# Latchline 1.0 TEST
Native Java/Canvas Android 8+ cargo puzzle. Switch between PUSH, moving cargo ahead, and PULL, dragging adjacent cargo directly behind you. In PULL mode walking into cargo is blocked. Dock the amber crate at the outlined receiver. Mode changes cost a move. Twelve rooms, unlimited undo/reset, saved palette and direction labels, GG007 menu/studio/privacy.

Actual Java exhaustive position/crate/mode BFS confirms 12 rooms, shortest10-17moves. Solution/undo/replay/mode tests pass. Native drawing/input adapter checks menu/settings/privacy/levels/directions/mode/win/undo/replay/next/persistence. Adapter previews are not Android screenshots. Phone runtime/performance/browser handoff QA incomplete. Not Play published or final-ready.

Functional overlap scan:803 historical registry entries, no playable push/pull cargo match; Crate Math is packing arithmetic, not spatial cargo mechanics. Unlike prior phase gate, slide-to-stop, paired-courier or relay games, the state includes independently moved cargo and persistent push/pull mode. This is a known puzzle genre, not a claim of global invention.
